# 東京オリンピック2020・エンブレム・パズル

パラリンピックのエンブレムを、オリンピックのエンブレムに組み替えるパズルです。

[パズルで遊ぶ](https://tatt61880.github.io/tyo2020pzl/)

## 遊び方

- 赤い点で3枚、緑の点で2枚のピースを入れ替えます。
- 藍色の長方形がオリンピックのエンブレムの模様になれば完成です。
- 「レベル」で難易度を、「オプション」で色・模様・完成状態の表示を変更できます。

## セーブデータ

「セーブデータ」を開くと、Load・Undo・Redoを使えます。テキストエリアの文字列を控えておくと、後からLoadで盤面を再現できます。読み込んだ手順もUndoで巻き戻せます。

共有リンクにはレベルと手順が含まれます。URLの `level` はレベル、`s` はセーブデータです。

詳しい操作方法やパズルの背景は、公開ページをご覧ください。
